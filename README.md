# NetSim5G - Virtual 5G Network Testbed
 
 End to End Simulated 5G Network/Test Bed using Open5GS Core Network and srsRAN Project with Simulated RF Environment using ZMQ Libraries

 Design and implement a fully functional 5G network simulation using Open5GS as the core network and srsRAN for the radio access network (RAN), with a simulated RF environment using ZMQ libraries. Investigate the impact of varying network latency and packet loss on the throughput and reliability of the simulated 5G system.
